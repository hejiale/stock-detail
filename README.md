# 西方财富 · 行情工作台

React 18 + Ant Design 5 重写的行情桌面端。左侧为分组菜单（自选、全球股市、基金、债券、贵金属、原油、美联储、虚拟币），右侧为可排序、分页、富字段的行情表格。

## 开发

```bash
npm install
npm run dev
# http://127.0.0.1:5173
```

## 构建与本地服务

```bash
npm run build     # 产物输出到 dist/
node serve.mjs    # 自动服务 dist/，http://127.0.0.1:8787
```

## 功能

- **自选**：自选个股（A股/美股/港股/日股/韩股切换）、自选基金；本机 localStorage 保存。
- **全球股市**：A股、美股、港股、日股、韩股涨跌榜；涨幅/跌幅切换、分页、分时缩略图、一键加自选、点击行打开个股详情。
- **个股详情抽屉**：分时/近1月/近3月/近半年/近1年/今年走势、盘口数据、阶段表现、财务报告、十大股东、公司资料。
- **市场全景**：指数卡片、涨跌分布、行业/地域板块、板块成分股（A股/美股/港股/日股/韩股）。
- **基金**：开放式基金涨幅榜；基金详情（净值走势、阶段涨幅、持仓、历史净值）；自选基金增删与搜索。
- **债券**：国债/地方债/企业债/可转债，可转债展示正股、转股价、溢价率等扩展字段。
- **贵金属 / 原油 / 美联储 / 虚拟币**：分类行情、利率曲线、EFFR 历史、币安现货与 K 线详情。
- **账号**：登录 / 注册入口（自选数据在本地，登录仅用于账号展示/同步扩展）。
- **移动端**：桌面为固定侧栏，窄屏自动切换为抽屉菜单，表格可横向滚动。

## 目录

```
src/
  main.jsx                 入口、AntD 暗色主题
  App.jsx                  布局、侧栏菜单、页头搜索、全局弹层
  components/              表格单元格、图表、详情抽屉、板块抽屉、登录弹窗
  pages/                   各业务页面
  lib/market.js            行情/自选接口适配与格式化
api.js                     原行情接口（东方财富/新浪/腾讯/币安）
watchlist-api.js           原自选/登录接口
legacy.html + js/ + tabs/  旧版页面，保留作参考，不参与构建
```

行情数据来自东方财富、新浪财经、腾讯财经、纽约联储、币安等公开接口，仅供研究参考，不构成投资建议。
